# The Long Roast: Lawmakers and the File They Cannot Convert — make.fun entry

An entry for the make.fun competition **The Long Roast: Lawmakers and the File They Cannot Convert**.

`main.ts` (Node 22, stdlib only) writes one satirical sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The sentence (320 of the 320-character
cap, a single sentence) is split into a setup and a punchline constant and
joined at runtime; the program validates length and single-line shape
before writing and produces byte-identical output on every run.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The entry: lawmakers regulate AI, crypto and the internet before lunch,
then spend the afternoon stuck on a PDF they cannot open — and sign a law
about a document none of them had managed to read.
